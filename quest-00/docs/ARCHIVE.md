# Archive

This file keeps old notes about the gate.
Most of them are no longer used.

## History of the Gate

The gate was built a long time ago.
In the beginning, anyone could open it without a key.

## Gate Words (Version 1)

In version 1, the secret word was **candle**.
This word was removed in version 2 and does not work anymore.

## Deprecated: Old Gate Words

The words below are deprecated. Please do not use them:

- `torch`
- `candle`

They were replaced in version 3.
The current secret word is **lantern**.

## Ideas for Version 4

We might change the secret word to **moonlight** in the future.
This is only an idea. It is not in use yet.
