# Code of Conduct

We want this project to be a friendly place where everyone can learn.
Many of us are writing in English for the first time. Mistakes are normal here.

## We do

- Be kind and patient.
- Assume good intentions.
- Give feedback about the work, not about the person.
- Say thank you when someone helps you.
- Ask questions when something is not clear.

## We do not

- Make fun of someone's English, skills, or mistakes.
- Use insulting, rude, or discriminatory words.
- Share other people's private information.
- Share answers or flags that spoil the quests for others.

## If something goes wrong

If you see or experience behavior that breaks this code,
tell the maintainer (the guild master) in class or in private.
The maintainer may edit or delete comments, close issues and pull requests,
or block users who break this code.

This code of conduct is inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/), which many open source projects use.
